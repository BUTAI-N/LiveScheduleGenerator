# BUTAI LIVE Schedule

TikTokストーリーズ向けの「配信スケジュール画像」をブラウザだけで作るWebアプリです。
サーバー不要・ビルド不要（HTML / CSS / JavaScript のみ）。スマホ対応。

**▶ 公開ページ： https://butai-n.github.io/LiveScheduleGenerator/**

入力した内容と設定はブラウザの中だけに保存されます。サーバーには何も送信されません。

## 使い方

1. 上記の公開ページを開く（またはローカルで `index.html` を開く）
2. **期間** → **スケジュール入力** → **デザイン** → **テキスト** の順に設定
3. **画像を保存（PNG）** で `LiveSchedule_YYYYMMDD.png` を書き出し（YYYYMMDD = スケジュールの初日）

### ローカルで動かす

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます。
（`index.html` をダブルクリックして開いても動作しますが、ブラウザによっては設定の保存が効かないことがあります）

### 公開する

静的ホスティング（GitHub Pages / Cloudflare Pages / Netlify など）にフォルダをそのまま置けば動きます。

## 機能

| 項目 | 内容 |
| --- | --- |
| 期間 | 今日から1〜7日間（デフォルト） / 1週間（曜日はじまりを選択可・前後の週へ移動可） |
| 入力 | 日ごとに開始・終了（任意）・内容・休み。内容はドロップダウン（雑談・ゲーム・作業・歌枠・ASMR・カスタム自由入力）。1日に最大3枠（朝配信・夜配信など）。前の週からコピー |
| 時刻 | 時は0〜29時（24以降は深夜＝翌日）、分は10分刻みのセレクト式。「頃」の付け方を選択可（開始と終了 / 開始のみ / なし）。分が00のとき「20時」と書く表記も選択可 |
| 表示 | 左に曜日と日付、右に「雑談 20:00頃～22:00頃」の形式で内容と時間。終了時間が無いときは「20:00頃～」。文字サイズは全行共通で、収まる範囲で自動的に最大化。複数枠は開始時刻順に横並びで、入らない分だけ折り返す。曜日と日付は縦積み／横並びを自動で切り替え |
| 曜日 | 日本語（月・火…）／英語（MON・TUE…）から選択。初期値は日本語 |
| レイアウト | かわいい / かっこいい / シンプル |
| カラー | かっこいい系7色 + かわいい系7色（TikTokカラー・モノクロ含む）+ カスタム |
| フォント | Google Fonts 日本語17種（丸ゴシック系・シンプル系・かっこいい系） |
| 書き出し | 1080×1920（TikTokストーリーズ推奨）/ 1440×2560 / 720×1280 / 1080×1350 / 1080×1080 |
| セーフゾーン | TikTok UI が重なる目安をプレビューに表示（書き出し画像には含まれない） |
| 保存 | 設定と入力内容はブラウザ（localStorage）に自動保存 |

## 書き出しサイズについて

TikTokストーリーズは **9:16 / 1080×1920px** が推奨です。
上部 150〜200px・下部 250〜300px・右 120px にはTikTokのUIが重なるため、本アプリは上下に余白を確保して配置しています。

## ファイル構成

```
index.html        画面
css/style.css     UIスタイル
js/presets.js     サイズ・フォント・カラー・レイアウトの定義
js/render.js      Canvas描画（プレビューと書き出しで共通）
js/app.js         状態管理・UI・保存・書き出し
```
